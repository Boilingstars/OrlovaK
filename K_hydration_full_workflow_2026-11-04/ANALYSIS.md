## Главный вывод

При GFN2-xTB/ALPB(water) K⁺ держит **почти полную первую оболочку только при n = 4–6**. Уже при n = 7 глобальный минимум — открытая структура (КЧ MDAtom 5,1; K–O до 3,63 Å; 4 H-связи вода–вода). Это раньше, чем у Cs⁺ в той же методике (там оболочка держалась до n = 7). С n ≥ 8 ион уходит к поверхности водяного кластера: среднее `#water` ~5–6,5, растут `surface_index` и сетка H-связей.

Нужное КЧ = n как рабочая модель **первой** оболочки **не найдено** в поиске для n ≥ 7 ни по порогу MDAtom 0,15, ни по геометрическому sweep «все K–O ≤ 3,2 Å». Это `NOT_FOUND_IN_SEARCH`, не доказательство физической невозможности. Финальный ACCEPT по XYZ остаётся за человеком.

## n = 7–14: поверхность и вторая сфера

С n = 7 картина ломается раньше, чем у Cs (там перелом n = 8–9).

1. **КЧ больше не растёт с n.** Среднее `#water` падает с 5,81 (n = 6) до 4,84 (n = 7), затем медленно 4,91 → 6,51 к n = 14. Диагональ КЧ = n на `coordination_vs_n.png` расходится с n = 7.
2. **⟨K–O⟩ скачок.** Уникальные минимумы: 2,65 Å (n = 6) → 2,95 Å (n = 7) → плато ~3,38–3,40 Å (n = 12–14). Рост среднего — из дальних вод, не растяжение первой сферы (K–O min остаётся ~2,39–2,47 Å).
3. **Поверхностный K⁺.** `surface_index` 0,003 (n = 6) → 0,145 (n = 7) → 0,25–0,29 (n = 8–12). К n = 14 чуть снижается (0,195): больше вод, но ион всё ещё не в центре.
4. **Ориентация.** Геометрический биссектрисный параметр ~1,00 при n = 4–6, 0,90 при n = 7, затем 0,71 → 0,35. Часть молекул смотрит в сетку воды, не на ион.
5. **H-связи вода–вода** (уникальные минимумы): 0 / 0 / 0 при n = 4–6, затем 2,1 → 5,2 → 7,2 → 9,5 → 11,3 → 13,1 → 15,3 → 17,4.
6. **Контакты K–O > 3,4 Å:** 0 при n = 4–6; 1,7 при n = 7; до 8,0 при n = 14.

Физическая интерпретация в рамках GFN2-xTB/ALPB и данного поиска: с n = 7 дополнительная вода идёт во **вторую сферу / водородно-связанный кластер**, а не достраивает первую оболочку. Это `NOT_FOUND_IN_SEARCH` для КЧ = n, не доказательство невозможности.

Сравнение с Cs при той же методике: Cs держал почти полную оболочку до n = 7 и переходный n = 8 (все Cs–O ≤ 4,0 Å, КЧ 7,4–7,8); K рвёт оболочку уже на n = 7.

## Что можно и нельзя говорить в рукописи

Можно:

- K⁺(H₂O)ₙ, GFN2-xTB/ALPB, 100 стартов: компактная первая оболочка для n = 4–6; ⟨K–O⟩ ~2,47–2,65 Å.
- С n ≥ 7 в этом поиске доминируют открытые / поверхностные минимумы с КЧ MDAtom ~5–6,5.
- `radius[A]` — взвешенное среднее, не граница.
- Сравнение с Cs: у калия срыв полной оболочки раньше (n = 7 vs n = 8).

Нельзя без оговорок:

- сравнивать E(n) как гидратацию;
- выдавать больцмановские веса по E как населённости;
- ставить ACCEPT по одному `#water`;
- утверждать, что КЧ = n при n ≥ 7 невозможно;
- считать поиск полным для n ≥ 7;
- переносить 3,04 Å в характеристику оболочки.

Пилот `smoke_3` не входит в сотню `full_100`.
